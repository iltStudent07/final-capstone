Project Task Tracker

A modern project management suite built with React, Express and MongoDB. Organize projects, track tasks, and collaborate with your team - all in one place.

Key Features

Dashboard

Real-time overview of all projects and tasks with status breakdowns and priority distrubution.

Project Managment

Create projects, assign team members, set timelines, and track progress from planning to completion.

Task Tracking

Create, assign, and prioritize tasks. Track status through todo, in-progress, review, and done.
